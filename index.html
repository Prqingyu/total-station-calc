使用说明

三个模式

  1. 盘左：输入每个测回两个目标的水平度盘读数 A、B，角值 = B 读数 − A 读数（不够减时加 360°），再对各测回角值直接平均。
  2. 盘右：按与盘左相同的 A → B 目标顺序填盘右读数，算法与盘左相同；汇总时左右取平均得到一测回。
  3. 距离：每个方向一组，填入所有水平距离，自动平均并给出极差。

一个测站处理完，先在“汇总”里复制结果，再点各模式右上角“清空”，即可录入下一个测站。

计算公式

半测回角值 = (读数 B − 读数 A + 360°) mod 360°
一测回角值 = (盘左半测回 + 盘右半测回) ÷ 2
各测回平均值 = 各一测回角值的算术平均
距离均值 = 同方向各次距离的算术平均

精度与取整

角度按 0.01″ 计算与显示（非整数秒保留两位小数）。距离按“四舍六入五成双”取至毫米，均值下方同时给出未取整到毫米的数值（最多 5 位小数）。

限差提示按 DJ6 常用指标：半测回互差 ≤ 40″，各测回互差 ≤ 24″，仅作参考。

快捷输入

度、分、秒分三格填写，输入满格会自动跳到下一格。也可以直接把 125°35′00″ 或 125 35 00 粘贴进任意一格。

装到手机桌面

Android：用 Chrome 打开页面 → 右上角菜单 → “添加到主屏幕”。
iPhone：用 Safari 打开 → 分享按钮 → “添加到主屏幕”。

首次打开后应用会缓存，之后没有网络也能计算。
